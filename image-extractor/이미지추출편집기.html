⚠️ 지금은 파일을 직접 연 상태라 공개 프록시(불안정)를 거쳐 페이지를 가져옵니다. 같은 폴더의 이미지추출편집기-실행.bat을 더블클릭해서 열면 내 컴퓨터가 직접 가져오므로 훨씬 잘 됩니다.

페이지 소스 또는 이미지 주소 붙여넣기

상대 경로는 위 주소창의 URL을 기준으로 해석합니다.

사용 방법

1. 주소로 추출 — 주소를 넣고 [이미지 추출]. 이미지추출편집기-실행.bat으로 열면 내 컴퓨터가 직접 페이지를 가져옵니다(권장). HTML 파일만 직접 열면 공개 프록시를 거치며, 잘 안 될 수 있습니다.
2. 로그인이 필요하거나 스크립트로 그려지는 페이지 — 아래 버튼을 브라우저 북마크바로 끌어다 놓고, 대상 페이지에서 그 북마크를 클릭하세요. 이미지 주소가 복사되면 [소스/주소 붙여넣기]에 붙여넣습니다.
   📋 이미지 주소 복사
3. 직접 넣기 — 이미지 파일을 끌어다 놓거나, 화면 캡처 후 Ctrl+V.
4. 편집 — 썸네일을 클릭하면 편집기가 열립니다: 자르기 · 회전 · 반전 · 크기 · 밝기/대비/채도 · AI 누끼 · 색 지우기 · 지우개/복원 브러시.
AI 누끼는 처음 한 번 모델(약 40~80MB)을 내려받고, 이후 이미지는 내 컴퓨터 안에서 처리됩니다.
