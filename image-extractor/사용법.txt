이미지 추출 편집기 - 사용법
==============================

[준비물]
- Windows 10 / 11 (설치할 프로그램 없음)
- 크롬 또는 엣지 브라우저
- 인터넷 연결

[실행 방법]
1. ZIP 파일을 마우스 오른쪽 클릭 → "압축 풀기" (꼭 압축을 푼 뒤 실행하세요)
2. 풀린 폴더에서 "이미지추출편집기-실행.bat" 더블클릭
3. 브라우저가 자동으로 열립니다 (http://localhost:8765)
   - 검은 창(서버)은 쓰는 동안 켜 두세요. 다 쓰면 그 창을 닫으면 종료됩니다.

* 처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜨면
  → "추가 정보" 클릭 → "실행" 클릭
* 방화벽 허용 창이 뜨면 "취소"해도 됩니다 (내 컴퓨터 안에서만 쓰므로)

[사용 방법]
1. 주소창에 웹페이지 주소 입력 → [이미지 추출]
2. 최소 크기 숫자로 작은 아이콘 숨기기
3. 체크 후 [선택 항목 ZIP 다운로드] 또는 카드의 [저장]
4. 썸네일 클릭 → 편집기
   ★ 누끼 순서: 선택(AI 자동 선택 또는 클릭 선택) → 마스크 확인·브러시로 수정 → [✅ 누끼 실행]
     · 선택 결과는 바로 적용되지 않고 "마스크"로 표시됩니다 (노란 선 안쪽 = 남는 부분)
     · ➕ 포함 브러시: 빠진 부분을 칠해서 추가 / ➖ 제외 브러시: 남은 배경을 칠해서 빼기
       (지우개·복원 버튼을 눌러도 마스크 확인 중에는 각각 제외·포함 브러시로 동작)
     · [반전] 남길 곳/지울 곳 뒤집기, [취소] 또는 Esc로 마스크 버리기
     · Ctrl+Z로 마스크 수정 한 단계씩 되돌리기, Enter = 누끼 실행
   - 🎯 클릭으로 물체 선택 (AI): 배경과 색이 비슷할 때 가장 정확
     · 남길 물체를 클릭 → 선택 밖이 어둡게, 경계는 노란 선으로 표시
     · 빠진 부분은 더 클릭(+), 잘못 잡힌 곳은 우클릭 또는 Shift+클릭(−)
     · [이 물체 남기기 →] / [이 물체 지우기 →] 를 누르면 마스크 확인 단계로 넘어감
     · 처음 한 번 모델 다운로드 + 이미지 분석에 몇 초~수십 초, 이후 클릭은 1초 이내
   - 🪄 테두리 다듬기 (누끼 직후 슬라이더를 움직이면 바로 반영, 되돌리기 한 번에 원래대로)
     · 안쪽으로: 테두리를 0~6px 깎아 배경색 띠(헤일로) 제거
     · 부드럽게: 경계를 0~8px 흐려 계단 현상 없이 자연스럽게 (기본 1px / 1.5px)
     · AI 자동 누끼나 브러시로 다듬은 뒤에도 사용 가능
   - AI 자동 선택: 주인공 물체를 자동으로 찾아 마스크로 표시 (처음 1회 모델 다운로드로 20초~1분)
     · AI 모델: 표준(빠름) / 고품질(정확, 첫 다운로드 큼)
     · 배경과 제품 색이 비슷하면: [배경과 색이 비슷할 때] 체크 + 고품질 모델
     · [자르기 영역 선택]으로 제품을 먼저 감싼 뒤 AI 자동 선택 → 그 안에서만 찾아서 더 정확
     · 포장 봉지처럼 겉면에 사진이 인쇄된 제품은 인쇄된 사진만 잡을 수 있으니 클릭 선택 권장
   - 색 지우기: 클릭한 색과 비슷한 배경을 투명하게 (로고·단색 배경용)
   - 지우개 / 복원 브러시: 누끼 가장자리 다듬기
   - 자르기, 회전, 반전, 크기 조절, 밝기·대비·채도 보정
   - 기울기: 슬라이더(±45°, 0.1° 단위)로 수평 맞추기. 격자를 보며 맞춘 뒤 [기울기 적용]
     ("빈 모서리 잘라내기"를 끄면 잘라내지 않고 모서리를 투명하게 남김)
   - 확대/축소: 마우스 휠 (커서 위치 기준), 위쪽 [− + 맞춤 1:1] 버튼
   - 화면 이동: 도구를 고르지 않은 상태에서 드래그, 또는 휠 버튼을 누른 채 드래그
   - 단축키: Ctrl+Z 되돌리기, Ctrl+Y 다시, Ctrl+S 저장, Ctrl+Shift+S 다른 이름으로 저장, Esc 닫기
   - 저장 형식: PNG(투명 유지) / JPG / WebP
   - [다른 이름으로 저장]: 저장 창에서 파일 이름·폴더를 직접 고름 (확장자 .png/.jpg/.webp로 형식 결정)

[이미지가 잘 안 나올 때]
- 로그인이 필요하거나 스크롤해야 그려지는 페이지는 [도움말]의
  "📋 이미지 주소 복사" 버튼을 북마크바로 끌어다 놓고,
  대상 페이지에서 그 북마크를 클릭 → 편집기의 [소스/주소 붙여넣기]에 붙여넣기
- 이미지 파일을 끌어다 놓거나, 캡처 후 Ctrl+V 해도 편집할 수 있습니다.

[파일 구성]
- 이미지추출편집기-실행.bat : 실행 파일 (이걸 더블클릭)
- server.ps1               : 웹페이지를 대신 받아오는 내 컴퓨터용 서버
- 이미지추출편집기.html      : 프로그램 화면

※ 가져온 이미지는 원 저작자의 저작권과 사이트 이용약관을 지켜 사용하세요.
