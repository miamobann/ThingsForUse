# image-extractor

웹페이지 주소를 넣으면 이미지를 모두 뽑아 보여 주고, 바로 편집·누끼(배경 제거)까지 하는 Windows용 도구. 설치 없이 Windows 기본 PowerShell + 크롬/엣지로 동작.

## 사용

1. 이 폴더의 파일 3개(`이미지추출편집기.html`, `server.ps1`, `이미지추출편집기-실행.bat`)를 한 폴더에 받는다.
2. `이미지추출편집기-실행.bat` 더블클릭 → 브라우저에서 `http://localhost:8765`가 열림. 검은 창은 쓰는 동안 켜 두고, 닫으면 종료.
   - "Windows의 PC 보호"가 뜨면 추가 정보 → 실행. 방화벽 창은 취소해도 됨.
3. 주소 입력 → [이미지 추출]. 최소 크기로 아이콘 숨기기, 체크 후 ZIP 다운로드.
4. 썸네일 클릭 → 편집기.

로그인이 필요하거나 스크립트로 그려지는 페이지는 [도움말]의 "📋 이미지 주소 복사" 북마클릿을 북마크바에 끌어다 놓고, 대상 페이지에서 눌러 복사한 주소 목록을 [소스/주소 붙여넣기]에 넣는다. 이미지 파일 끌어다 놓기, 캡처 후 Ctrl+V도 됨.

## 편집기

| 기능 | 내용 |
|---|---|
| 누끼 | 선택 → 마스크 확인·브러시 수정 → [✅ 누끼 실행]. 선택 결과는 바로 적용하지 않고 마스크(노란 선 안쪽이 남음)로 보여 줌 |
| AI 자동 선택 | 주인공 물체 자동 인식. 표준/고품질 모델, 저대비 보정, 자르기 영역을 잡아 두면 그 안에서만 |
| 클릭 선택 | 물체 클릭(+), 우클릭·Shift+클릭(−). 색이 비슷한 배경, 겉면에 사진이 인쇄된 포장 제품에 강함 |
| 마스크 브러시 | ➕ 포함 / ➖ 제외, 반전, Ctrl+Z 단계 되돌리기, Enter 실행, Esc 취소 |
| 테두리 다듬기 | 안쪽으로 0~6px(배경색 띠 제거), 부드럽게 0~8px. 누끼 직후 슬라이더로 바로 반영 |
| 색 지우기 | 클릭한 색과 비슷한 영역 투명 (허용 오차, 이어진 영역만) |
| 지우개·복원 | 복원은 누끼 전 원본 픽셀을 다시 그림 |
| 자르기·회전 | 영역 자르기, 투명 여백 자르기, 90° 회전, 반전, 기울기 ±45°(격자, 빈 모서리 자동 자르기) |
| 크기·색 | 크기 조절(비율 유지), 밝기·대비·채도·흐림·흑백 |
| 보기 | 휠 확대/축소(커서 기준), 드래그 이동, 맞춤·1:1, 배경 체크무늬/흰/검정 |
| 저장 | PNG(투명)·JPG·WebP, 다른 이름으로 저장(Ctrl+Shift+S), 클립보드 복사, 되돌리기 30단계 |

## 구조

- `server.ps1`: `localhost:8765`에서 HTML을 보여 주고 `/proxy?url=`로 페이지·이미지를 대신 받아 옴(브라우저 CORS·핫링크 차단 회피). 이 PC·사설망 주소는 거부.
- `이미지추출편집기.html`: 화면 전부. 추출(DOMParser로 img·srcset·lazy·og:image·CSS 배경·스크립트 안 주소), 편집(canvas).
- HTML만 직접 열면 공개 프록시를 거치는데 불안정함. bat으로 실행 권장.

## 보안·외부 통신

- AI 모델은 처음 한 번 내려받고 이후 이미지는 브라우저 안(WebAssembly)에서 처리. 이미지를 서버로 올리지 않음.
  - 자동 선택: `@imgly/background-removal` 1.5.5 (esm.sh, 모델 staticimgly.com)
  - 클릭 선택: `@huggingface/transformers` 3.0.2 + `Xenova/slimsam-77-uniform` (jsdelivr, huggingface.co)
  - ZIP: JSZip 3.10.1 (cdnjs)
- 추출 대상 페이지 주소는 `server.ps1`(내 PC)이 직접 요청. 파일만 직접 연 경우에만 공개 프록시(allorigins 등)로 전송됨.
- 가져온 이미지는 원 저작자의 저작권과 사이트 약관을 지켜 사용.
