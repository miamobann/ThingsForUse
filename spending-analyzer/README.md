# 지출 분석

가계부 앱이 기록한 지출 내역을 올리면 세부 분류·습관·고정 지출·추세를 보여주는 **웹페이지 파일 하나**예요. 설치가 필요 없고, 인터넷 없이 PC 브라우저에서 열려요.

## 쓰는 법

1. `지출분석.html`을 받아서 더블클릭 (크롬·엣지 권장)
2. 구글 드라이브의 `가계부_내역_전체.csv`를 창에 끌어다 놓기
3. **분류하기** 탭에서 처음 보는 가게의 대분류·세부 분류를 고르기 (한 번 고르면 기억)

현대카드 명세서·실시간 이용내역(.xls)과 네이버페이 내역 CSV도 바로 읽어요. 같은 종류·같은 기간 파일을 다시 올리면 새 파일로 바뀌어요.

## 화면

| 탭 | 내용 |
|---|---|
| 대시보드 | 기간 선택, 세부 분류별 지출(대분류 → 세부 → 내역), 월별 추세와 직전 3개월 대비 변화, 요일별 습관, 자주 가는 곳, 소액 반복, 큰 지출, 고정 지출 |
| 내역 | 전체 내역 표. 정렬·필터·검색, 분류 바로 고치기(같은 가게 전부/이 건만), 지출에서 빼기·넣기, 할부는 월 금액·남은 금액 표시 |
| 분류하기 | 분류 안 된 가게 목록(금액 큰 순), 가게 이름으로 미리 고른 추천, AI 자동 분류, 결제대행사 건은 한 건씩, 세부 분류 목록 편집 |
| 점검 | 파일을 합치며 한 일, 중복 의심, 짝 없는 결제, 지출에서 뺀 것, 환불 |
| 파일·설정 | 불러온 파일, 송금 제외 옵션, 가계부 앱용 CSV 저장, 백업 파일 저장·불러오기, AI 키, (웹 앱) 앱 연결 비밀번호 |

## 여러 파일을 합칠 때

- 같은 id는 한 건
- 현대카드 명세서 ↔ 실시간 이용내역: 같은 날·같은 금액이면 시각이 있는 실시간 쪽 하나로 (해외결제는 청구액 사용)
- 카드의 '네이버파이낸셜·네이버페이' 결제 ↔ 네이버페이 내역: 금액·시각으로 짝지어 네이버페이 쪽 가게 이름 사용
- 네이버페이로 냈는데 카드엔 결제대행사·가게 이름(예: 이니시스 - 팬딩)으로 찍힌 결제도 같은 대행사·같은 금액이면 짝
- 네이버페이 상품 금액엔 배송비가 빠져 있어, 같은 날 같은 가게 상품 합계 + 5천원 이하 = 카드 금액이면 한 주문
- 포인트를 섞어 낸 결제는 카드로 나간 금액만 지출
- 이미 취소 처리된 결제의 카드 환불(음수)은 두 번 빼지 않음

## 구글 시트로 쓰기 (가계부 앱과 연결)

같은 화면을 구글 앱스 스크립트 웹 앱으로 띄우면, 가계부 앱이 보낸 내역을 시트에서 읽고 분류도 시트에 저장해요.

- 시트 '내역': 가계부 앱만 써요 (앱 CSV와 같은 14열).
- 시트 '분류 자료': 이 화면만 써요 (종류, 키, 대분류, 소분류, 값). 단, 종류 '건별' 줄의 대분류는 앱과 같이 읽고 써요. 여기서 고친 대분류는 다음 동기화 때 앱에 들어가고, 앱에서 고친 대분류는 '다시 읽기'하면 여기 보여요.
- 현대카드 .xls·네이버페이 CSV를 올려 비교하는 건 창 안에서만 하고 시트엔 저장하지 않아요.

설정 순서
1. 구글 드라이브에서 새 구글 시트를 만들어요 (이름 자유).
2. 시트 메뉴 확장 프로그램 → Apps Script. 기본 `Code.gs` 내용을 `apps-script/Code.gs`로 바꾸고, 파일 `Sync.gs`(가계부 앱 쪽 `budget-app/apps-script/Sync.gs`)를 추가해요. HTML 파일을 `Index` 이름으로 추가하고 `apps-script/Index.html` 내용을 붙여 넣어요 (`python3 build.py`가 만들어요).
3. 배포 → 새 배포 → 유형 '웹 앱', 실행: **나**, 액세스: **모든 사용자**. 처음엔 권한 허용 화면이 나와요(시트 읽기·쓰기, 외부 요청은 AI용).
4. 나온 웹 앱 주소를 구글에 로그인한 브라우저로 열면 분석 화면이에요. 다른 사람이 열면 막혀요.
5. 파일·설정 탭 → '가계부 앱 연결 비밀번호'를 8자 이상으로 정하고, 가계부 앱에 웹 앱 주소와 같은 비밀번호를 넣어요.
6. (처음 한 번) 파일·설정 → 백업 불러오기로 예전 분류 백업을 넣으면 가게별 기억과 건별 분류가 옮겨져요. 건별 분류는 날짜·시각·금액·가게로 새 id를 찾아 붙여요.
7. (선택) AI 자동 분류 키는 파일·설정에서 넣으면 스크립트 속성에 저장돼요.

코드를 고친 뒤엔 Apps Script에서 배포 → 배포 관리 → 수정 → 새 버전으로 올려야 웹 앱 주소에 반영돼요.

## 구글 결제 메일 읽기 (선택, `apps-script/Mail.gs`)

시트와 같은 구글 계정의 Gmail에서 Google Play 영수증을 읽어 시트 '메일'에 적어요. 카드 알림엔 "Google"만 찍히는 결제에 앱 이름과 상품명을 붙이려는 보완용이에요. AI를 쓰지 않아요.

- 5분마다 최근 2일 메일 중 Google Play 영수증(보낸 곳·제목)만 찾아요. 새 메일이 없으면 바로 끝나요.
- 규칙으로 주문 날짜·시각(GMT 표기를 한국 시각으로), 합계, 상품명, 앱 이름(상품명 끝 괄호), 결제 방법을 뽑아요. 환불 메일은 '취소'.
- 분류: '분류 자료'의 가게 기억 → 단어 규칙 순. 없으면 정기 결제는 '구독'으로 추정, 그 외는 비워 둬요.
- '내역'에서 금액이 같고 시각 차이 15분 이내인 앱 기록 id를 '내역 id'에 적어요. 같은 결제 메일이 두 통이면 '확인 필요'에 표시해요.
- 읽은 메일은 숨김 시트 '메일 기록'에 남아 다시 읽지 않아요. '내역'과 '분류 자료'는 읽기만 해요.
- 설정: Apps Script에 `Mail.gs` 추가 → `mailSetup` 실행(Gmail 권한 허용). 지난 90일은 `mailBackfill90`, 멈추려면 `mailStop`, 못 읽은 메일 본문 확인은 `mailShowLast`.
- Gmail엔 "메일이 오면 바로" 실행되는 트리거가 없어서 5분 간격으로 확인해요.

## 데이터와 AI

- 파일로 열면 내역과 분류는 그 PC 브라우저에만 저장돼요. 웹 앱으로 열면 위의 구글 시트에 저장돼요. 백업 파일로 옮길 수 있어요(내역은 빠지고 분류만).
- AI 자동 분류(선택)는 Anthropic API 키가 필요하고, **분류 안 된 가게 이름과 분류 목록만** 보내요. 금액·날짜는 보내지 않아요. 제안은 승인해야 저장돼요.

## 개발

- `src/core.js`: 파일 읽기·합치기·분류·분석 (브라우저/Node 공용)
- `src/app.js`, `src/style.css`, `src/index.html`: 화면
- `apps-script/Code.gs`: 웹 앱 서버 쪽 (시트 읽기·저장, AI 호출)
- `python3 build.py` → `지출분석.html`, `apps-script/Index.html` 생성
- `node --test test/core.test.js` (가짜 데이터로 테스트)
