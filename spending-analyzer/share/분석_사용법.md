# 지출 분석 사용법

가계부 앱이 기록한 지출을 PC에서 자세히 나눠 보는 화면이에요. 두 가지 방법으로 쓸 수 있어요.

| 방법 | 파일 | 내역이 오는 곳 | 분류가 저장되는 곳 |
|---|---|---|---|
| 구글 시트 웹 앱 (추천) | `Code.gs`, `Sync.gs`, `Index.html` | 가계부 앱이 시트로 보낸 내역 | 같은 구글 시트 |
| 파일 하나로 | `지출분석.html` | 가계부 앱이 내보낸 CSV를 끌어다 놓기 | 그 PC의 브라우저 |

구글 시트 설정 방법은 README.md에 있어요.

## 탭

- **대시보드**: 기간을 고르면 세부 분류별 지출, 월별 추세, 요일별 습관, 자주 가는 곳, 큰 지출, 고정 지출을 보여 줘요. 막대를 누르면 내역이 펼쳐져요.
- **내역**: 전체 내역 표예요. 정렬·검색할 수 있고, 대분류·세부 분류를 바로 고칠 수 있어요. '같은 가게 전부' 또는 '이 건만'을 골라요. 지출에서 빼거나 다시 넣을 수도 있어요.
- **분류하기**: 세부 분류가 안 된 가게를 금액 큰 순으로 보여 줘요. 한 번 고르면 같은 가게는 앞으로 자동으로 분류돼요. "토스페이먼츠"처럼 결제대행사 이름만 있는 건은 상품명을 보고 한 건씩 고르거나, 단어 규칙("이 단어가 들어가면 이 분류")을 만들어요. 세부 분류 목록도 여기서 고쳐요.
- **점검**: 같은 결제가 두 번 잡혔을 수 있는 건을 보여 줘요. 중복이면 하나를 빼고, 아니면 '중복 아님'을 눌러요.
- **파일·설정**: 현대카드 이용내역(.xls), 네이버페이 내역 CSV를 올려 비교할 수 있어요. 분류 백업 저장·불러오기, AI 키, 가계부 앱 연결 비밀번호(웹 앱일 때)도 여기 있어요.

## 분류 규칙

- 대분류는 가계부 앱과 같아요. 웹 앱으로 쓰면 여기서 고친 대분류가 다음 동기화 때 앱에도 들어가요.
- 세부 분류는 이 화면에만 있어요. 처음엔 대분류마다 기본 목록이 있고, 마음대로 더하거나 뺄 수 있어요.
- 우선순위: 한 건만 고친 분류 → 가계부 앱의 대분류 → 가게별 기억 → 단어 규칙.

## AI 자동 분류 (선택)

Anthropic API 키를 넣으면 '분류하기'에서 AI가 가게 이름을 보고 세부 분류를 제안해요. AI에는 분류 안 된 가게 이름과 분류 목록만 보내고, 금액·날짜는 보내지 않아요. 제안은 확인하고 저장해야 반영돼요. API 사용료는 키 주인에게 나와요.

## 주의

- 웹 앱 주소는 남에게 알려 주지 마세요. 시트 주인 계정으로 로그인해야만 열리지만, 주소가 알려지면 가계부 앱 연결 비밀번호를 맞히려는 시도를 받을 수 있어요.
- 파일로 쓸 때는 브라우저 데이터를 지우면 분류도 지워져요. 파일·설정의 '백업 파일 저장'으로 가끔 저장해 두세요.
