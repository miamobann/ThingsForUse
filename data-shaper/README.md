# data-shaper

엑셀·CSV를 올려서 머리글·병합·소계를 정리하고, 가공 단계를 쌓아 원하는 형식으로 내려받는 단독 HTML 도구.

## 사용

1. `data-shaper.html`을 내려받아 크롬에서 연다 (더블클릭).
2. 파일을 끌어다 놓는다. 시트가 여러 개면 위에서 고른다.
3. 원본 읽기: 머리글 시작 줄·줄 수를 확인한다. 원본 탭에서 줄 번호를 누르면 그 줄부터 머리글로 지정.
4. 가공 단계를 추가한다. 위에서부터 순서대로 적용됨.
5. 원하는 열 구성이 정해진 양식이 있으면 "템플릿으로 열 맞추기"로 머리글만 있는 엑셀을 올린다.
6. 결과 형식(xlsx/csv) 고르고 내려받기.

규칙(읽기 설정·단계)은 "4 규칙"에서 이름을 붙여 "규칙 저장"하면 브라우저 저장소(localStorage)에 목록으로 쌓이고, 나중에 목록에서 골라 "적용"한다. 같은 이름으로 저장하면 덮어씀. "내보내기"는 목록 전체를 JSON 한 파일로, "가져오기"는 그 파일의 규칙을 목록에 추가(같은 이름은 덮어씀).

## 보안

- 새로고침 복원: 파일 내용과 작업 상태를 이 PC 브라우저(IndexedDB)에 저장해 같은 탭에서 새로고침하면 복원. 새 탭에서는 복원 안 하고, 닫힌 탭의 저장분은 2분 지나면 다음에 열 때 지움. 파일 이름 옆 "닫기"를 누르면 바로 지움

- 파일은 브라우저 메모리 안에서만 처리. 서버 전송 없음.
- HTML 안에 CSP(`connect-src 'none'` 등)를 넣어 브라우저가 외부 통신 자체를 막음.
- 엑셀 라이브러리(SheetJS 0.18.5 Apache-2.0: 값 읽기, ExcelJS 4.4.0 MIT: 서식 읽기·엑셀 쓰기)는 파일 안에 포함. 외부 CDN 호출 없음.
- 규칙에는 열 이름·필터 값이 들어감. 브라우저 저장소에 남으므로 공용 PC에서는 목록에서 삭제하고, 내보낸 JSON을 공유할 때는 내용 확인.

## 서식

엑셀로 내려받으면 원본 서식을 열 단위로 이어받는다.
- 머리글: 원본 머리글 마지막 줄 칸의 서식. 새로 생긴 열은 다른 머리글 서식을 따름
- 데이터: 각 열에서 값이 있는 첫 데이터 칸의 서식(글꼴·채우기·테두리·맞춤·숫자 형식)을 열 전체에
- 열 너비: 원본 열 너비
- 집계·피벗의 합계·평균·최소·최대 열은 숫자 형식만, 새 숫자 열은 천 단위 쉼표
- 템플릿을 쓰면 템플릿 머리글 칸·바로 아래 칸·열 너비가 원본보다 우선
- 결과 탭 "서식 보기"를 켜면 미리보기가 엑셀 서식대로 보임. 머리글을 누르면 그 열의 숫자 형식·굵게·글자색·배경색·맞춤·너비, 머리글 줄 전체 색·굵게를 고칠 수 있음. 편집한 서식이 가장 우선이고 규칙에 같이 저장됨 (열 이름 기준)
- .xls 원본은 숫자 형식만. 조건부 서식, 셀마다 다른 서식, 병합은 옮기지 않음

## 가공 단계

| 단계 | 내용 |
|---|---|
| 열 정리 | 고르기, 끌어서 순서 바꾸기, 이름 바꾸기 |
| 필터 | 같음·포함·크기 비교·다음 중 하나·빈 칸, 그리고/또는 |
| 정렬 | 여러 기준, 빈 값은 맨 뒤 |
| 중복 제거 | 기준 열 지정 또는 전체 열 |
| 값 바꾸기 | 공백 정리, 숫자로, 날짜 형식, 값 치환, 빈 칸 채우기 |
| 열 합치기·나누기 | 구분자 기준 |
| 계산 열 | `[단가] * [수량]`, `ROUND(값, 자릿수)`, `ABS(값)` |
| 집계 | 그룹별 합계·개수·행 수·평균·최소·최대·고유 개수 |
| 부분합 | 기준 열 값이 바뀔 때마다 소계 줄, 총합계. 엑셀에서 그룹별 +/− 접기 |
| 피벗 | 행 기준 × 열 기준 교차표, 합계 행·열. 화면에 예시 표, 엑셀에 "가이드" 시트 포함 |
| 템플릿 맞추기 | 템플릿 머리글 순서로 출력, 이름 비슷한 열 자동 연결 |

## 개발

```
python3 build.py              # src/ + vendor/ → data-shaper.html
node test/make-samples.js     # 가짜 테스트 데이터 생성 (test/samples/)
node test/e2e.js              # 브라우저 동작 + 외부 요청 0건 확인 (playwright)
python3 test/make-styled-sample.py && node test/e2e-style.js   # 서식 유지 확인
node test/e2e-reload.js       # 새로고침 복원 확인
```

`data-shaper.html`은 빌드 결과물. 수정은 `src/`에서 하고 빌드.
실제 사내 데이터는 저장소에 올리지 않는다. `test/samples/`는 전부 가짜 데이터.
