# data-shaper

엑셀·CSV를 올려서 머리글·병합·소계를 정리하고, 가공 단계를 쌓아 원하는 형식으로 내려받는 단독 HTML 도구.

## 사용

1. `data-shaper.html`을 내려받아 크롬에서 연다 (더블클릭).
2. 파일을 끌어다 놓는다. 시트가 여러 개면 위에서 고른다.
3. 원본 읽기: 머리글 시작 줄·줄 수를 확인한다. 원본 탭에서 줄 번호를 누르면 그 줄부터 머리글로 지정.
4. 가공 단계를 추가한다. 위에서부터 순서대로 적용됨.
5. 원하는 열 구성이 정해진 양식이 있으면 "템플릿으로 열 맞추기"로 머리글만 있는 엑셀을 올린다.
6. 결과 형식(xlsx/csv) 고르고 내려받기.

규칙(읽기 설정·단계)은 시트별로 브라우저 저장소(localStorage)에 자동 저장되고, 같은 시트 이름의 파일을 열면 자동 적용된다. 시트 이름이 Sheet1·CSV처럼 흔하면 파일 이름(숫자 제외) 기준. 다른 PC로 옮기거나 백업할 때는 "내보내기"(전체 규칙 JSON) → "가져오기".

## 보안

- 파일은 브라우저 메모리 안에서만 처리. 서버 전송 없음.
- HTML 안에 CSP(`connect-src 'none'` 등)를 넣어 브라우저가 외부 통신 자체를 막음.
- 엑셀 라이브러리(SheetJS 0.18.5, Apache-2.0)는 파일 안에 포함. 외부 CDN 호출 없음.
- 규칙에는 열 이름·필터 값이 들어감. 브라우저 저장소에 남으므로 공용 PC에서는 "초기화"로 지우고, 내보낸 JSON을 공유할 때는 내용 확인.

## 가공 단계

| 단계 | 내용 |
|---|---|
| 열 정리 | 고르기, 순서, 이름 바꾸기 |
| 필터 | 같음·포함·크기 비교·다음 중 하나·빈 칸, 그리고/또는 |
| 정렬 | 여러 기준, 빈 값은 맨 뒤 |
| 중복 제거 | 기준 열 지정 또는 전체 열 |
| 값 바꾸기 | 공백 정리, 숫자로, 날짜 형식, 값 치환, 빈 칸 채우기 |
| 열 합치기·나누기 | 구분자 기준 |
| 계산 열 | `[단가] * [수량]`, `ROUND(값, 자릿수)`, `ABS(값)` |
| 집계 | 그룹별 합계·개수·행 수·평균·최소·최대·고유 개수 |
| 부분합 | 기준 열 값이 바뀔 때마다 소계 줄, 총합계. 엑셀에서 그룹별 +/− 접기 |
| 피벗 | 행 기준 × 열 기준 교차표, 합계 행·열. 화면에 예시 표, 엑셀에 "가이드" 시트 포함 |
| 템플릿 맞추기 | 템플릿 머리글 순서로 출력, 이름 비슷한 열 자동 연결 |

## 개발

```
python3 build.py              # src/ + vendor/ → data-shaper.html
node test/make-samples.js     # 가짜 테스트 데이터 생성 (test/samples/)
node test/e2e.js              # 브라우저 동작 + 외부 요청 0건 확인 (playwright)
```

`data-shaper.html`은 빌드 결과물. 수정은 `src/`에서 하고 빌드.
실제 사내 데이터는 저장소에 올리지 않는다. `test/samples/`는 전부 가짜 데이터.
