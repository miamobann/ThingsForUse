# 네이버페이 결제내역 내보내기

크롬에서 로그인한 네이버페이 결제내역 페이지에 붙여넣어 쓰는 콘솔 스크립트. 비밀번호·쿠키는 스크립트 밖으로 나가지 않아요.

| 파일 | 하는 일 |
|---|---|
| `1-구조확인.js` | 페이지가 불러오는 데이터의 모양만 뽑아 `네이버페이_구조.txt`로 저장 (글자·숫자는 가려짐) |
| `3-정리.py` | 받은 CSV에서 같은 id 중복 삭제, 결제대행사 이름을 실제 가게로 변경, 확인할 건 목록 만들기 |
| `2-내보내기.js` | 결제내역을 1쪽부터 끝까지 읽어 CSV로 저장 (기본 2025-01-01부터) |

## 1단계: 구조 확인

1. 크롬에서 네이버 로그인 → 네이버페이 → **결제내역**
2. F12 → **Console** 탭 (처음이면 `allow pasting` 입력 후 Enter 해야 붙여넣기가 돼요)
3. `1-구조확인.js` 내용을 전부 붙여넣고 Enter → 20초쯤 기다리면 `네이버페이_구조.txt`가 받아져요
4. 현장결제·정기결제가 다른 탭이나 필터에 있으면, 그 화면으로 바꾼 뒤 한 번 더 실행

## 2단계: 내보내기

1. 크롬에서 https://pay.naver.com/pc/history 열기 (로그인 상태)
2. F12 → Console에 `2-내보내기.js` 전체 붙여넣고 Enter
3. 끝나면 두 파일이 받아져요 (크롬이 '여러 파일 다운로드'를 물으면 허용)
   - `네이버페이_결제내역_2025-01-01_오늘.csv` : 가계부 앱·분석 프로그램과 같은 14열
   - `네이버페이_원본_오늘.json` : 확인용 원본 (PC에만 보관)
4. 콘솔 표에 종류(serviceType)별 건수가 나와요

시작 날짜는 스크립트 맨 위 `FROM`을 바꾸면 돼요.

CSV 메모 열에는 상품명, 상태, 종류가 들어가요. 결제 목록 화면에 결제수단(카드/포인트)이 없어서 결제수단은 모두 '네이버페이'로 적혀요.
페이지가 쓰는 내부 주소(`/_next/data/…/pc/history.json?page=N`)는 네이버가 언제든 바꿀 수 있어서, 안 되면 1단계로 다시 구조를 확인해요.

## 3단계: 정리

```
python3 3-정리.py 네이버페이_결제내역_….csv
```

`…_정리.csv`(같은 14열)와 `…_확인목록.md`가 옆에 생겨요. 결제대행사로 찍힌 건은 `가게명`을 실제 가게로 바꾸고 `원래가게명`에 대행사 이름을 남겨요. 중복 의심, 금액 없음, 가게 모름은 지우지 않고 메모에 `[확인]`을 붙여요. 결제 데이터 파일은 저장소에 올리지 않아요.
