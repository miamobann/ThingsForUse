# maileditor

메일 양식(HTML)의 바뀌는 부분을 변수로 지정해 두고, 엑셀·CSV·JSON 데이터로 회사별 메일을 만들어 Outlook에 바로 붙여넣거나 .eml로 한 번에 뽑는 단독 HTML. 설치 없이 크롬/엣지에서 `메일양식변환기.html`을 열면 끝.

## 사용

1. **양식 입력/교체** → Outlook 등에서 복사한 양식을 붙여넣기(서식·이미지 유지) 또는 파일 열기(.html/.htm + 이미지, .eml, .mht, .txt). Outlook에서 HTML로 저장한 경우 `_files` 폴더째 [폴더 열기].
2. `[이름]`, `{{이름}}`은 자동으로 변수가 됨. 다른 부분은 드래그 → [선택 → 변수], 링크 주소가 바뀌는 곳은 [선택 → 링크 변수].
3. **① 변수**: 변수마다 값(데이터 열·고정값, 여러 개 합치기), 표시(그대로·날짜 형식·직접 수식 입력), 비어 있으면 줄 삭제, 값 변환표, 서식.
4. **② 데이터**: Excel·CSV·JSON 열기 또는 엑셀 표 붙여넣기. 열 이름이 비슷하면 변수에 자동 연결.
5. **③ 출력**: [본문 복사] → Outlook 새 메일 서명 위에 Ctrl+V. 또는 선택한 행을 .eml ZIP으로 저장 → 더블클릭하면 받는 사람·제목·본문이 채워진 새 메일(클래식 Outlook). .eml 방식은 서명이 자동으로 안 붙으니 삽입 → 서명.
6. **④ 검수**: 공란, 가공 실패, 다른 행과 형식이 다른 값을 행별로 표시. 문제없으면 [확인함].

양식은 이름 붙여 저장(브라우저 IndexedDB). [내보내기]로 JSON 백업, [가져오기]로 복원·다른 PC로 이동.

## 기능

| 기능 | 내용 |
|---|---|
| 양식 편집 | 굵게·기울임·밑줄, 글자색, 형광펜(진하기 조절·지우기), 크기, 링크, 이미지 삽입·교체, 실행 취소. PC 경로 이미지(받는 사람에게 안 보임)는 빨간 테두리로 경고 |
| 변수 값 | 데이터 열 / 고정값(담당자명 등), [+ 데이터 추가]로 여러 열 합치기(공백·쉼표·줄바꿈 등) |
| 직접 수식 입력 | 엑셀식 수식. `값`(합친 결과), `값1`·`값2`(각각), `[열 이름]`(다른 열). LEFT·RIGHT·MID·TEXTBEFORE·TEXTAFTER·SUBSTITUTE·TRIM·UPPER·PROPER·IF·IFS·SWITCH·IFERROR·TEXT·ROUND 등 + REGEXREPLACE·REGEXEXTRACT·SPLIT. 자주 쓰는 가공 14개 골라 넣기, 현재 행 결과·오류 바로 표시 |
| 값 변환표 | 데이터 값 → 다른 값 (예: 언어 EN → 영문 가이드 링크). 표에 없으면 원래 값/빈 값/기본값 |
| 줄 삭제 | 값이 비면 그 줄을 빈 줄 없이 통째로 삭제 (예: Date 2가 없는 회사) |
| 서식 | 기본은 원문 서식을 그대로 따름. 변수별로 굵게·색·크기 따로 지정 가능 |
| 출력 | 서식 유지 복사(Outlook용 인라인 스타일), 제목 복사, HTML 소스 복사, .eml 1건 / ZIP 일괄. 복사·저장한 행은 ✓ 표시 |
| 검수 | 빈 값·"-"·"N/A", 수식 오류, 이 행만 수식이 안 먹힘, 날짜로 안 읽힘, 변환표에 없는 값, 형식·자릿수·길이 이탈, 괄호 짝·끊긴 끝(잘림 의심), 이메일 형식·중복. 오류 행은 복사·저장 전에 확인 |

## 보안·외부 통신

- 양식·데이터는 브라우저 안에서만 처리. 서버로 보내지 않음.
- Excel(.xlsx/.xls) 파일을 열 때만 SheetJS 0.18.5를 cdnjs에서 내려받음. 인터넷이 없으면 엑셀 표를 복사해 붙여넣거나 CSV로 열면 됨.
- 저장한 양식과 마지막 데이터는 그 PC·그 브라우저의 IndexedDB에 남음. 브라우저 데이터를 지우면 사라지니 [내보내기]로 백업.
