# 가계부 (안드로이드)

결제할 때마다 자동으로 쌓이는 개인용 가계부 앱.

- **자동 기록:** 현대카드 앱 알림, 네이버페이 알림, 농협·현대카드 문자를 읽어서 저장
- **중복 합치기:** 같은 결제가 알림·문자·파일로 여러 번 와도 한 건. 카드에 "네이버파이낸셜"로만 찍힌 결제는 네이버페이 알림의 실제 가게 이름으로 바꿈
- **파일 올리기:** 현대카드 홈페이지의 이용대금명세서·실시간 이용내역(.xls), 분석 프로그램이 내보낸 가계부 CSV(분류·메모 그대로, 파일 안의 줄끼리는 중복 검사 안 함)
- **고정 지출:** 최근 몇 달 동안 매달 한 번, 비슷한 금액(10% 이내)으로 나간 결제를 찾아 홈에 '남은 고정 지출'로 표시. '고정 지출 아님'으로 뺄 수 있음
- **분류:** 가게별로 한 번 고르면 기억. 결제대행사 이름만 있는 결제는 매번 물어봄
- **통계:** 월별 총지출·전월 대비, 카테고리 원형 그래프, 날짜별 달력, 월 예산과 80%/100% 알림
- **구글 시트 연동:** 설정에 앱스 스크립트 웹 앱 주소와 연결 비밀번호를 넣으면 내역 전체를 시트 '내역'에 올리고, 분석 화면에서 고친 대분류(시트 '분류 자료'의 건별 줄)를 받아옴. 앱에서 고친 분류도 시트로 보냄. 시트 쪽 코드는 `apps-script/Sync.gs`
- **기타:** 현금 직접 입력, 송금 지출 포함/제외 스위치, 지문·비밀번호 잠금, 구글 드라이브 자동 저장(백업 JSON + 분석용 CSV)

결제 내역은 폰 안에 저장돼요. 밖으로 나가는 건 직접 연결한 드라이브 파일, 직접 연결한 구글 시트(앱스 스크립트 주소), 안드로이드 자체 백업뿐이에요. 시트 연동을 켜지 않으면 인터넷을 쓰지 않아요.

## 설치

1. GitHub 저장소의 **Releases → "가계부 앱 최신"** 에서 `budget-app.apk`를 폰으로 받기
2. 받은 파일을 눌러 설치 (처음이면 "출처를 알 수 없는 앱 설치 허용"을 켜야 해요)
3. 앱 실행 → **설정** 탭에서 권한 세 개 켜기
   - 알림 읽기 (현대카드·네이버페이)
   - 문자 받기 (농협·카드 문자)
   - 알림 보내기 (예산·분류 알림)
4. 알림 읽기나 문자 권한이 회색으로 막혀 있으면:
   휴대폰 **설정 → 애플리케이션 → 가계부 → 오른쪽 위 ⋮ → 제한된 설정 허용** 후 다시 켜기
   (안드로이드 13부터 직접 설치한 앱에 한 번 필요해요)
5. **설정 → 구글 드라이브 저장**에서 백업 파일과 CSV 위치를 고르기 (저장 위치 화면 왼쪽 메뉴의 "드라이브")

업데이트는 새 APK를 받아 그대로 설치하면 돼요. 같은 키로 서명돼서 데이터가 유지돼요.

## 이중 기록 막기

| 경우 | 처리 |
|---|---|
| 같은 결제가 카드 알림·문자·파일로 여러 번 | 금액+시각(또는 승인번호)으로 한 건 |
| 현대카드를 네이버페이에 등록해 결제 | 카드("네이버파이낸셜")와 네이버페이 알림을 한 건으로, 가게 이름은 네이버페이 쪽 |
| 네이버페이 포인트+카드로 나눠 결제 | 금액이 달라도 몇 분 안이면 한 건, 금액은 카드로 나간 돈 (메모에 포인트 사용액) |
| 네이버페이 결제가 카드엔 PG·가게 이름으로 찍힘 (이니시스, 나이스정보통신 등) | 금액 같고 몇 분 안이면 한 건 (금액이 다르면 1분 안일 때만) |
| 네이버페이 알림 금액에 배송비가 빠짐 | 카드가 5,000원 이내로 더 크면 한 건, 금액은 카드 쪽 (메모에 차이) |
| 한 주문이 네이버페이 알림 여러 개로 옴 | 이미 합쳐진 카드 결제(더 큰 금액) 3분 안이면 그 결제에 묶음 |
| 택시: 명세서엔 차량번호("택시-경기 65 바 …"), 알림엔 "카카오T일반택시" | 둘 다 택시면 같은 가게로 봄 |
| 농협에서 현대카드 대금 출금 | '카드대금'으로 기록하고 지출에서 뺌 |
| ATM 현금 인출 | '현금인출'로 기록하고 지출에서 뺌 (현금은 쓸 때 직접 입력) |
| 택시·주유 가승인 | 지출에서 뺌 (실제 결제가 따로 옴), 가승인 취소가 오면 취소 처리 |
| 해외결제 등 알림 금액과 청구 금액이 다름 | 같은 가게·같은 날·10% 이내면 한 건, 금액은 파일(청구액)로 고침 |

| 다음 달에 들어온 취소·환불 | 자동으로 짝짓지 않고 그 달에 따로 남김 → 직접 상계 |
| 더치페이로 돌려받은 입금 | 농협 입금을 '입금'으로 모아 둠(지출 아님) → 원래 결제와 상계하면 결제 금액이 줄어듦 |

**상계:** 내역을 눌러 '상계하기'에서 짝을 고르면, 금액이 같으면 둘 다 지우고, 돌려받은 돈이 적으면 결제 금액을 그만큼 줄여요.
**할부:** 결제한 달에 전체 금액으로 잡고, 내역에 '전체 · 월 금액 · 남은 금액(개월)'을 보여줘요.

지출에서 뺀 건도 내역에는 남고, 눌러서 '지출에 포함'을 다시 켤 수 있어요.

## 구조

```
budget-app/
  core/   안드로이드와 무관한 로직 (알림·문자·파일 읽기, 중복 판단, 통계) + 테스트
  app/    안드로이드 앱 (알림 리스너, 문자 수신, SQLite 저장, Compose 화면)
```

- `core`만 테스트: `./gradlew -PcoreOnly :core:test`
- 실제 카드 파일로 확인: `BUDGET_SAMPLES=<xls 폴더> ./gradlew -PcoreOnly :core:test --tests '*SampleFilesCheck*' -i`
  (개인 결제 내역이라 파일은 저장소에 넣지 않아요)
- APK 빌드는 GitHub Actions(`.github/workflows/budget-app.yml`)가 `budget-app/` 변경마다 해요.

## 알림 문구가 바뀌어서 못 읽을 때

못 읽은 알림·문자는 **설정 → 읽지 못한 알림·문자**에 원문이 쌓여요. 그 문구를 보고
`core/src/main/kotlin/budget/core/MessageParsers.kt`의 규칙과 테스트를 고치면 돼요.

## 분석용 CSV 열

`id, 날짜, 시각, 금액, 가게명, 원래가게명, 카테고리, 결제수단, 할부, 송금여부, 지출포함여부, 취소됨, 메모, 출처`

- 취소된 결제는 금액이 양수로 남고 `취소됨=Y` (합계에서 빼야 함). 짝을 못 찾은 환불(다음 달 환불 포함)과 입금은 금액이 음수.
- 카테고리 '카드대금', '현금인출', '입금'은 `지출포함여부=N`.
- 카드 월 명세서에서 온 결제는 시각이 비어 있음.
