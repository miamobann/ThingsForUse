# 가계부

결제할 때마다 자동으로 쌓이는 안드로이드 가계부 앱과, PC에서 지출을 자세히 보는 분석 프로그램이에요.
분석 프로그램은 쓰는 사람의 구글 시트에서 돌아가고, 앱과 시트가 서로 내역과 분류를 주고받아요.

```
가계부/
  가계부.apk          안드로이드 앱
  README.md           이 설명서
  분석 프로그램/       구글 시트 앱스 스크립트에 붙여넣을 파일
    Code.gs
    Sync.gs
    Index.html
    지출분석.html      시트 없이 쓰는 분석 프로그램 (파일 하나)
    분석_사용법.md     분석 화면 탭별 사용법
```

## 1. 앱이 자동으로 읽는 것

| 결제 수단 | 읽는 방법 |
|---|---|
| 현대카드 | 현대카드 앱 알림, 현대카드 결제 문자(문자 앱 알림으로) |
| 네이버페이 | 네이버페이(네이버 앱) 결제 알림. 현대카드와 같이 오면 한 건으로 합치고 가게 이름은 네이버페이 쪽을 써요 |
| 농협은행 | 입출금 문자, 문자 앱 알림으로 읽음 (출금은 '송금', 입금은 '입금'으로 기록) |
| 현대카드 파일 | 현대카드 홈페이지 이용대금명세서·실시간 이용내역(.xls)을 앱의 '파일 올리기'로 |
| 그 밖의 결제 | 홈의 '+ 현금 입력'으로 직접 입력 |

다른 카드사·은행의 알림과 문자는 아직 자동으로 읽지 못해요. 그런 결제는 직접 입력해 주세요.
읽지 못한 결제 알림·문자는 **설정 → 읽지 못한 알림**에 원문이 모여요.

## 2. 앱 설치

1. `가계부.apk`를 폰으로 옮겨요(카카오톡 나에게 보내기, 구글 드라이브 등).
2. 파일을 눌러 설치해요. 처음이면 "출처를 알 수 없는 앱 설치 허용"을 켜야 해요.
3. 앱을 열고 **설정** 탭에서 권한 세 개를 켜요.
   - 알림 읽기 (카드·네이버페이·문자 앱). 농협·카드 문자도 문자 앱의 알림으로 읽어서 문자 권한은 쓰지 않아요. 문자 앱 알림은 켜 두세요.
   - 알림 보내기 (예산·새 가게 분류 알림)
4. 알림 읽기가 회색으로 막혀 있으면 휴대폰 **설정 → 애플리케이션 → 가계부 → 오른쪽 위 ⋮ → 제한된 설정 허용**을 누른 뒤 다시 켜요. 안드로이드 13부터 직접 설치한 앱에 한 번 필요해요.
5. 홈 화면에서 월 예산을 정해요(**설정 → 예산**).

### 설치가 막힐 때 ("기기 보호를 위해 앱 차단됨")

구글이 금융 사기를 막으려고, 카톡·파일 앱으로 받은 앱이 '알림 읽기' 권한을 쓰면 설치를 막아요. 이 앱은 결제 알림을 읽어야 해서 이 권한이 꼭 필요해요.

1. Play 스토어 → 오른쪽 위 프로필 → **Play 프로텍트** → 오른쪽 위 톱니바퀴 → **Play 프로텍트로 앱 검사**를 꺼요.
2. `가계부.apk`를 다시 눌러 설치해요.
3. 설치가 끝나면 **Play 프로텍트로 앱 검사**를 다시 켜요. 이미 설치한 앱은 지워지지 않아요.

통화 중에는 끌 수 없으니 통화가 아닐 때 해 주세요. "유해할 수 있는 앱" 경고만 뜨면 **자세히 → 무시하고 설치**로도 돼요.

앱은 결제 내역을 폰 안에 저장해요. 밖으로 보내는 건 직접 연결한 구글 시트와 구글 드라이브 파일, 안드로이드 자체 백업뿐이에요.
시트 연동을 켜지 않으면 인터넷을 쓰지 않아요.

### 앱 기능 요약

- 가게별로 카테고리를 한 번 고르면 다음부터 자동 분류 (네이버파이낸셜 같은 결제대행사 이름은 매번 물어봐요)
- 월별 총지출과 지난달 같은 날 대비, 카테고리 원형 그래프, 날짜별 달력, 월 예산 80%·100% 알림
- 매달 나가는 고정 지출 찾기 (홈의 '남은 고정 지출')
- 같은 결제가 두 번 잡혔을 수 있으면 홈에 '중복 의심'으로 알려 줘요
- 받은 결제 알림·문자 원문과 처리 결과 기록 (**설정 → 받은 결제 알림 기록**)
- 카드대금 출금, ATM 인출, 택시·주유 가승인은 지출에서 자동으로 빼요
- 입금·다음 달 환불은 모아 두었다가 원래 결제와 '상계' (더치페이 정산)
- 할부는 결제한 달에 전체 금액으로, 내역에 전체·월·남은 금액 표시
- 송금을 지출에 넣을지 전체·건별로 선택, 지문·비밀번호 잠금
- 구글 드라이브 백업 파일 자동 저장과 복원 (**설정 → 구글 드라이브 저장**)

## 3. 분석 프로그램

두 가지로 쓸 수 있어요. 자세한 사용법은 `분석 프로그램/분석_사용법.md`에 있어요.

- **구글 시트 웹 앱 (추천):** 앱과 자동으로 연동돼요. 아래 4번 설정을 해요.
- **파일 하나로:** `지출분석.html`을 크롬으로 열고, 앱의 **설정 → 구글 드라이브 저장 → 분석용 내역 (CSV)**로 저장한 파일을 끌어다 놓아요. 분류는 그 PC 브라우저에 저장돼요.

## 4. 구글 시트 연동

PC 크롬에서 1~5, 폰에서 6, 다시 PC에서 7을 해요. 처음 한 번만 하면 돼요. 10분쯤 걸려요.

### PC: 시트와 분석 화면 만들기

1. 쓰는 사람 본인 구글 계정으로 **새 구글 시트**를 만들어요. 이름은 자유예요(예: 가계부).
2. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 열어요.
3. `분석 프로그램` 폴더의 파일 세 개를 넣어요.
   - 처음 있는 `Code.gs` 내용을 모두 지우고 **Code.gs** 내용을 붙여넣어요.
   - 파일 목록 옆 **+ → 스크립트**로 `Sync`를 만들고 **Sync.gs** 내용을 붙여넣어요.
   - **+ → HTML**로 `Index`를 만들고 **Index.html** 내용을 붙여넣어요.
   - 저장(Ctrl+S)해요.
4. 오른쪽 위 **배포 → 새 배포**에서 톱니바퀴를 눌러 **웹 앱**을 골라요.
   - 실행: **나**
   - 액세스 권한: **모든 사용자**
     (폰 앱이 로그인 없이 보내야 해서 필요해요. 연결 비밀번호가 맞아야만 읽고 쓰고, 분석 화면은 시트 주인 계정이 아니면 열리지 않아요.)
   - **배포 → 권한 허용**을 눌러요. "확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 눌러요. 본인이 만든 스크립트라서 나오는 경고예요.
   - 나오는 **웹 앱 주소**(`https://script.google.com/macros/s/…/exec`)를 복사해 둬요.
5. 그 주소를 크롬에서 열면 분석 화면이 떠요. **파일·설정 탭 → 연결 비밀번호**를 8자 이상으로 정해요.

### 폰: 앱 연결하기

6. 앱 **설정 → 구글 시트 연동**에 4번의 웹 앱 주소와 5번의 비밀번호를 넣고 **저장하고 연결**을 눌러요.
   "동기화됨"이 뜨면 시트의 '내역' 탭에 모든 내역이 올라간 거예요. 주소를 폰으로 옮길 땐 카카오톡 나에게 보내기가 편해요.

### PC: 분석 화면 보기

7. 분석 화면에서 **다시 읽기**를 누르면 앱 내역이 보여요.

### 그다음부터

- 결제하면 앱이 기록하고 몇 초 뒤 시트 '내역'에 올려요. 인터넷이 없으면 다음에 연결될 때 올려요.
- 분석 화면에서 대분류를 고치면 다음에 앱을 열 때 앱에도 반영돼요. 앱에서 고친 대분류도 시트로 가요.
- 시트 파일 이름 끝에 마지막 동기화 날짜가 붙어요(예: 가계부_261103). 끄려면 Apps Script **프로젝트 설정 → 스크립트 속성**에 `RENAME_WITH_DATE` = `off`를 넣어요.
- 시트의 '내역' 탭은 앱이 매번 통째로 다시 써요. 직접 고치지 말고 앱이나 분석 화면에서 고쳐 주세요.
- 스크립트 코드를 새 버전으로 바꿨다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 눌러야 반영돼요. 주소는 그대로예요.

### 연동이 안 될 때

| 앱에 뜨는 말 | 확인할 것 |
|---|---|
| 연결 비밀번호가 맞지 않아요 | 분석 화면에서 정한 비밀번호와 앱에 넣은 비밀번호가 같은지 |
| 시트에 연결 비밀번호가 아직 없어요 | 5번(분석 화면에서 비밀번호 정하기)을 했는지 |
| 시트 응답이 이상해요 | 4번에서 액세스 권한을 '모든 사용자'로 배포했는지, 주소가 `/exec`로 끝나는지 |
| 시트가 로그인을 요구해요 (401·403) | 배포 관리에서 액세스 권한이 '모든 사용자'인지('Google 계정이 있는 모든 사용자' 아님), 주소가 `/dev`가 아니라 `/exec`로 끝나는지. 고친 뒤 새 버전으로 다시 배포 |
| 연결 실패 | 폰 인터넷 연결 |
